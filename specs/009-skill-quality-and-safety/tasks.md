## Blocking dependencies

**Rule:** tickets that edit the same file never run concurrently. The implementation plan batches tickets by skill directory.

- **Code-only tickets:** T04, T13 and the validator part of T06 run in parallel with skill-text work.
- **Security text tickets:** T01, T02, T03 and T05 run first, in that order where they share files (triage, wayfinder, to-tickets, to-spec, setup-agent-tracker, ingest, chrome-test, obsidian-memory).
- **Content tickets:** T07–T12 and T14 follow; T12 needs T04.
- **Descriptions:** T06's frontmatter edits run after every other ticket that edits the same SKILL.md.
- **Evals:** T15 runs after T06 and T14.
- **Housekeeping:** T16 runs after all content.
- **Verification:** T17 runs last.
